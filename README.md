# Painel PAEX 2026 · Bioclin

Relatório BI (estilo Power BI) das 6 linhas estratégicas PAEX 2026: meta x realizado, alcance por linha, cascata de desvios, evolução mensal e FCAs.

- Arquivo único: `index.html`, abre direto no navegador, sem instalar nada.
- Acesso por senha: os números ficam criptografados (AES-256) dentro do arquivo e só aparecem com a senha correta. A senha não está escrita neste repositório.
- Dados até agosto/2026. Fonte: INDICADORES PAEX 2026.xlsx.
